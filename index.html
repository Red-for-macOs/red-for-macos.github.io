Red for Mac

Red is a native macOS front-end for Redis. It delivers an intuitive view of your data with live updating keys, pub/sub monitoring, an interactive console, and seamless Lua script integration.

Live Updates

Watch keys created and deleted in real-time. Stay synchronized with your Redis instance without manual refreshes.

Interactive Console

Visualize Redis commands as they execute. The interface refreshes instantly, aiding learning or complex workflows.

Lua Scripts

Develop, test, and run Lua scripts directly in Red. Add comments to prompt for dynamic values during execution.

Tabbed Windows & Dark Mode

Switch effortlessly between Redis instances with tabbed windows. Native Dark Mode support for macOS.

Detailed Views

Inspect data as Unicode strings, hexadecimal, JSON, or MsgPack in an expansive detail pane.

Native Swift Performance

Built exclusively for macOS in Swift. Fast, efficient, and energy-conscious.

How It Works

1. Connect

Enter your Redis server details. Red connects securely and loads your data instantly.

2. Explore

Browse keys in real-time. Use tabs for multiple instances and switch views as needed.

3. Interact

4. Inspect

Dive into details with formatted views. Export or script as your workflow demands.
